# 中文威胁情报来源

| 来源 | 官方网站 | 自动化方式 |
|---|---|---|
| 微步在线 X 情报社区 | https://x.threatbook.com/ | 账号确实有域名分析 API 权限时才启用 |
| 奇安信威胁情报中心 | https://ti.qianxin.com/portal/ | 可选网页查询；未核实通用免费自动化 API |
| 腾讯安全威胁情报中心 | https://tix.qq.com/ | 可选网页查询；未核实通用免费自动化 API |

免费网页查询不等于免费 API。Skill **不会使用非公开接口爬取登录网站**，也不会自动声称已检查。自动检查以允许调用的 API 和本地公开名单为准，来源不可用时如实记录。

微步域名 API：`https://api.threatbook.cn/v3/domain/query`。配置向导只在用户已获得该接口权限时开启。程序区分原生实验室情报、奖励计划情报和转载公开情报，不把转载的同一信号当作多个独立来源。

用户如已有经过合法获取的网页核验记录，可以使用 `audit --domestic-evidence 文件.json` 自行导入，但这不是普通用户运行 Skill 的必要步骤。不要把示例数据当成真实证据。
