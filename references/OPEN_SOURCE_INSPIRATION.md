# 开源设计参考

该 Skill 借鉴了开源安全分析项目的设计方法，但原始查询和报告代码独立实现。

- [Performing IOC Enrichment Automation](https://github.com/mukul975/Anthropic-Cybersecurity-Skills)：多源情报统一状态与证据处理。
- [Recon a Domain Passively](https://github.com/UseOSINT/Skills)：默认被动调查、明确范围、追溯来源与时间。
- [VirusTotal API Skill](https://github.com/w33ts/virustotal-api-skill)：API Key 引导、官方许可和查询限额意识。
- [IntelOwl](https://github.com/intelowlproject/IntelOwl)：后续可参考统一适配器思路，但本项目保持轻量 CLI。

不因多个渠道命中而简单投票；不把未检出与未查询混为一谈；不向公开威胁情报平台发送账号、私有 URL 或凭据。使用各 API 时尊重提供方当前条款，用户取得的 Key 不代表已获得任何额外使用许可。
