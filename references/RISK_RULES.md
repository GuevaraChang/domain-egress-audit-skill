# 风险判断逻辑

| 结果 | 触发条件 | 建议 |
|---|---|---|
| 发现严重风险 | 已提供可靠且经验证的明确高风险证据 | 不建议访问，调查后再决定 |
| 发现可疑问题 | 域名非常新、异常解析、公开历史跨域跳转或信誉平台发现可疑引擎结果 | 暂缓访问，核实线索 |
| 信息不足 | 关键检查失败、DNS 不可用、没有可用的在线域名信誉 API 数据，且未发现已知线索 | 补齐检查，谨慎对待 |
| 暂未发现明显风险 | DNS 与已获许可的域名信誉检查成功，且没有触发本工具的重大风险规则 | 可以谨慎访问，仍需核实网站身份 |

说明：公开信息未命中不等于安全。域名年龄、证书历史和 IP 归属本身并不构成恶意或可信证明。VirusTotal 的多个引擎结果需要看分析日期；urlscan 的历史跳转不代表当下仍然跳转。历史快照变化是调查线索，不是恶意证据。API 出错不计作零命中。仅在用户明确启用时执行 TLS 主动连接。

HTML 首屏包含结论、问题、已检查/未完成项目和建议；源数据折叠。JSON 保留证据链接、查询时间和原始结构化字段。输出不会自动修改网络策略。


## 本地 IOC 名单判断

- PhishShield **精确 FQDN 命中**：列为可疑信号，给出原始名单/更新时间，不单靠社区条目确定恶意。
- IPGuard **解析 IP 命中**：通常为弱关联；云主机、CDN、共享 IP 尤其需要审慎判断。
- anti-AD：广告/跟踪背景信息，低优先级，不判恶意。
- 本地数据缺失、过期或更新失败：显示“未检查/名单过期”，不显示绿色正常。
- 更新失败不能擦除有效缓存；不向数据源发送用户检测的域名。
